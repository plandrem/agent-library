# Apple

Install this bundle on Apple dev machines to unblock Claude Code for internal work.

## Included

- `apple-identity` skill — resolve DSID, AppleConnect credentials, Westgate JWT for internal service auth
- `sandbox-access` skill — unblock tools, commands, and domains restricted by the Apple Claude Code sandbox
- `apple-claude-code-expert` agent — reference lookup for Apple Claude Code (install, config, security, MCP, monitoring, architecture)

## Usage

Zero value outside Apple. High value together on a fresh internal machine — one pull gets the setup context a new ACC user needs to start being productive.
