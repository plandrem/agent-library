# Meta

Tooling for extending Claude Code itself — authoring new skills, agents, commands, and the specs that drive them.

## Authoring

- `/build_skill` — create a new Claude Code skill
- `/build_expert_agent` — create an expert agent with auto-generated index
- `/new_agent` — add a new custom agent
- `/new_command` — add a new custom slash command

## Specification pipeline

- `/spec` — write a technical specification for a new feature
- `/build_prd` — convert a plan into a PRD
- `spec-review` agent — catches ambiguities, unhandled cases, and acceptance-criteria gaps in specs/plans before implementation begins

## Usage

Pull this bundle when onboarding a project that will grow its own agentic tooling, or when designing a feature pipeline from scratch.
